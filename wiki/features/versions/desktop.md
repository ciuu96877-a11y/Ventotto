# Гра на комп'ютері

## Опис

На Windows гру запускають через безкоштовний рушій Godot 4.7.2. Можна запустити файлом «Play Ventotto.cmd» або відкрити проєкт у Godot.

## Поведінка

- Запускаєш `outputs/Ventotto/Play Ventotto.cmd` → якщо Godot 4.7.2 стоїть у звичайній папці (`%LOCALAPPDATA%\Programs\Godot\`), гра відкривається.
- Godot там немає → вікно з написом «Godot 4.7.2 was not found. Open project.godot from the Godot Project Manager.»
- Відкриваєш `outputs/Ventotto/project.godot` у Godot і тиснеш F5 → гра запускається. Першого разу треба почекати, поки імпортуються моделі й текстури.
- Гра відкривається у вікні 1280×720, і все в ній масштабується під розмір вікна.
- На весь екран — через [налаштування](../start/settings.md) («Полный экран»).
- Готового .exe у репозиторії немає. Щоб його зібрати, у Godot треба заново вибрати шаблони експорту: зараз там шляхи з комп'ютера автора.
