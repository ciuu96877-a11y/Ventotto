# Кінець рейсу

Рейс закінчується одним із трьох способів: ти доїхав, трамвай зійшов з рейок, або водій програв бійку.

- [Завершення рейсу](finish.md) — доїхав до вокзалу.
- [Сходження з рейок](derailment.md) — злетів з колії.
- Програна бійка описана на сторінці [Бійка в салоні](../passengers/difficult/fight.md).
