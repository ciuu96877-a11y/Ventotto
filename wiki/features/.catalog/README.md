# Каталог функцій

Тут записано, які функції є в грі і з яких файлів вони зроблені.
На кожен розділ вікі є один YAML-файл.

Поля кожної функції:

- `name` — назва функції так, як її бачить гравець.
- `page` — сторінка у вікі (шлях від папки `wiki/`).
- `links` — файли, де про функцію щось *обіцяють* (README, написи в меню, коментарі).
- `code` — файли, де функцію зроблено (шлях від кореня репозиторію).
- `tests` — тести. Тестів у репозиторії поки немає, тому список порожній.

## Словник (Domain)

Одне слово на одне поняття. Написи в самій грі російською, вони наведені в лапках «».

| Термін | Що означає |
|---|---|
| Трамвай | Вагон, яким керує гравець (у грі «Вагон 1565»). |
| Рейс | Одна поїздка від Погулянки до Залізничного вокзалу. |
| Зупинка | Місце, де беруть і висаджують пасажирів. Їх 9. |
| Кінцева | Остання зупинка — Залізничний вокзал. |
| Позначка F | Стовпчик із літерою F біля зупинки. Кабіна має стати навпроти нього. |
| Кабіна | Місце водія з важелями та приладами. |
| Тяга | Скільки сили дає мотор: від 0 до 5 («Тяга»). |
| Гальмо | Звичайне гальмо: від 0 до 4 («Тормоз»). |
| Реверсор | Напрям руху: Вперед, Нейтраль, Назад («Реверсор»). |
| Живлення | Головний вимикач. Без нього мотор не працює («Питание»). |
| Екстрене гальмування | Найсильніше гальмо, клавіша Space. |
| Обмеження швидкості | Найбільша безпечна швидкість на ділянці або в повороті. |
| Поворот | Крива ділянка колії. Перед нею стоїть табличка «КРИВА». |
| Перехрестя | Місце, де колію перетинає дорога зі світлофором. |
| Сходження з рейок | Трамвай злетів з колії. Рейс закінчено. |
| Складність | Легка, Середня або Важка («Лёгкий», «Средний», «Тяжёлый»). |
| Пасажир | Людина, яка їде в трамваї. |
| Складний пасажир | Пасажир, який кличе водія і створює проблему. |
| Розмова | Водій підходить до пасажира (клавіша G) і обирає дію 1–4. |
| Бійка | Сутичка з пасажиром: удари, блок, здоров'я. |
| Диспетчер | Людина на зв'язку, яка може прислати допомогу. |
| Репутація | Оцінка водія від 0 до 100. На старті 60. |
| Заробіток | Гроші за зміну в гривнях («За смену»). |
| Оголошення | Голос, який називає зупинки і говорить за пасажирів. |
| Субтитри | Текст оголошення внизу екрана. |
| Панелі | Усі віконця з цифрами поверх гри. |
| Підказка | Віконце зі знаком «!», яке каже, що робити далі. |
| Схема маршруту | Список зупинок, відкривається на Tab. |
| Вид з кабіни / Вид ззовні | Дві камери, перемикаються на R. |
| Швидкий сценарій | Запуск одного складного пасажира прямо з меню. |
| Пауза | Зупинка гри на Esc. |
