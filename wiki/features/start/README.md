# Початок гри

Що бачиш одразу після запуску і як почати рейс.

- [Головне меню](main-menu.md) — перший екран гри.
- [Пауза](pause.md) — як зупинити гру і продовжити.
- [Налаштування](settings.md) — звук, миша, графіка.

Складність обирати не треба: рейс починається одразу. Погода в кожному рейсі своя, див. [Погода, дощ і калюжі](../route/rain.md).
