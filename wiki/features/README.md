# Функції гри

Тут описано, як гра працює **зараз**, очима гравця.
Кожна сторінка — одна функція: що це таке і що відбувається, коли ти щось робиш.

## Як читати сторінки

- **Опис** — коротко, що це за функція.
- **Поведінка** — список правил у форматі «що робиш → що стається».
- **Розбіжності** — якщо README чи меню обіцяють інше, ніж робить гра, там є посилання.
