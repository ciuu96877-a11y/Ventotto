# Гра в браузері

## Опис

Є версія, яка грається прямо в браузері, посилання на неї в README репозиторію. Гра та сама, але трохи спрощена, щоб швидше працювати.

## Поведінка

- Відкриваєш веб-версію → місто вже зібране наперед, тож гра стартує швидше.
- Будинки й предмети далі ніж ~165 м від трамвая не показуються, вони з'являються, коли під'їжджаєш.
- Тіней немає на будь-якій якості графіки.
- У [налаштуваннях](../start/settings.md) немає перемикача «Полный экран».
- Деякі значки замінені простими символами: ◆ → `>`, ● → `*`, ○ → `o`, ← → `<`, ◉ → «П».
- Шрифт простіший, а лічильник пасажирів трохи дрібніший.
- Усе інше (керування, пасажири, складності, дощ) працює так само, як [на комп'ютері](desktop.md).
