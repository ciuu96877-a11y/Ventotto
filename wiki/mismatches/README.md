# Розбіжності

Місця, де README, меню, знаки в грі або числа в коді обіцяють одне, а гра робить інше.
Головне завжди те, як гра працює **насправді**. Обіцянки, яких гра не виконує, записані тільки тут.

Типи:

- **не зроблено** — обіцяють, а в грі цього немає;
- **працює інакше** — є, але не так, як написано;
- **не використовується** — налаштування є, але гра його не бере до уваги.
