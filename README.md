# Ventotto — Львів

3D-игра о работе водителя трамвая: городской маршрут, пассажиры, погодные условия и управление из кабины.

## Запуск проекта

Исходный проект Godot находится в `outputs/Ventotto`. Откройте `outputs/Ventotto/project.godot` в Godot 4.7.2 и запустите главную сцену клавишей F6 или весь проект клавишей F5. При первом открытии дождитесь импорта моделей и текстур.

Модели, звуки, текстуры и скрипты входят в репозиторий. Кэш Godot, готовые EXE/Web-сборки, временные инструменты и данные авторизации исключены через `.gitignore`.

Редактируемая сцена трамвая, кабины и деталей салона для Blender находится в `art/tram-interior.blend`. Игровые материалы и свет дополнительно настраиваются в `cab.gd`; положение тела водителя задаётся в `driver.gd`.

## Управление

- A / D — положение контроллера тяги; Q / E — тормоз.
- Z — реверсор; K — питание; Space — экстренное торможение.
- F — двери; V — дворник; L — свет; B — звонок.
- R — переключение вида из кабины и внешней камеры.
- Мышь — осмотр; Tab — карта; H — панели; M — голосовые объявления.
- Enter — начать заново после схода; Esc — пауза.

## Сборка

В `export_presets.cfg` сохранены Windows и Web. Пути к пользовательским шаблонам экспорта настроены для исходного рабочего компьютера; на другом компьютере их нужно выбрать заново в настройках экспорта Godot. Web-сборка использует однопоточный шаблон и заранее подготовленную сцену `web_world.scn`.
