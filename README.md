# Ventotto — Львів

3D-игра о работе водителя трамвая: городской маршрут, пассажиры, погодные условия и управление из кабины.

## Запуск проекта

Исходный проект Godot находится в `outputs/Ventotto`. Откройте `outputs/Ventotto/project.godot` в Godot 4.7.2 и запустите главную сцену клавишей F6 или весь проект клавишей F5. При первом открытии дождитесь импорта моделей и текстур.

Модели, звуки, текстуры и скрипты входят в репозиторий. Кэш Godot, готовые EXE/Web-сборки, временные инструменты и данные авторизации исключены через `.gitignore`.

Редактируемая сцена трамвая, кабины и деталей салона для Blender находится в `art/tram-interior.blend`. Игровые материалы и свет дополнительно настраиваются в `cab.gd`; положение тела водителя задаётся в `driver.gd`.

## Управление

- A / D — положение контроллера тяги; Q / E — тормоз.
- Z — реверсор; K — питание; Space — экстренное торможение.
- F — двери; V — дворник; L — свет; B — звонок.
- R — переключение вида из кабины и внешней камеры.
- Мышь — осмотр; Tab — карта; H — панели; M — голосовые объявления.
- Enter — начать заново после схода; Esc — пауза.
- G — подойти к пассажиру после остановки и вернуться к управлению.
- 1–4 — действия в разговоре; в драке ЛКМ — удар, ПКМ или Shift — блок.

## Пассажиры и смена

В одиночном режиме есть пьяный пассажир, недовольная бабушка и проверка билетов. Конфликт можно решить разговором, высадкой на остановке или через диспетчера. Драка учитывает здоровье, выносливость, блок и задержку между ударами. Бабушке можно пообещать 20 секунд плавной езды; выполнение обещания приносит чаевые.

Счётчик «За смену» показывает оплату проезда, чаевые и штрафы. Репутация зависит от решений. Сценарии можно запустить прямо из главного меню. Настройки звука, чувствительности мыши, угла обзора и качества графики сохраняются между запусками. Мультиплеер в этой версии не включён.

## Сборка

В `export_presets.cfg` сохранены Windows и Web. Для Windows путь к пользовательскому шаблону экспорта настроен для исходного рабочего компьютера; на другом компьютере его нужно выбрать заново в настройках экспорта Godot. Web использует стандартный однопоточный шаблон Godot 4.7.2 и заранее подготовленную сцену `web_world.scn`.

Каждый push в `main` собирает Web-версию в GitHub Actions (`.github/workflows/web.yml`) и публикует её на GitHub Pages: https://ciuu96877-a11y.github.io/Ventotto/
