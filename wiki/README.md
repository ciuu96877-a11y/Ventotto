# Вікі «Вентотто — Львів»

**«Вентотто»** — гра, де ти водій старого трамвая у Львові. Треба провезти рейс від Погулянки до Залізничного вокзалу: зупинятися на зупинках, возити пасажирів, не злетіти з рейок у поворотах і впоратися зі складними пасажирами.

Вікі описує, як гра працює **зараз**, очима гравця. Написи в самій грі українською, тут вони наведені в лапках «» як є.
