# Досягнення

## Опис

За особливі вчинки в рейсі гравець отримує досягнення. Їх 19, кожне можна отримати один раз, і гра пам'ятає їх між запусками.

## Поведінка

- Натискаєш «Досягнення» в [головному меню](main-menu.md) → відкривається вікно «ДОСЯГНЕННЯ N / 19» зі списком: назва і що треба зробити.
- Отримані досягнення в списку жовті, ще не отримані — сірі.
- Натискаєш «Повернутися · Esc» або Esc → вікно закривається.
- Отримав досягнення → угорі екрана на ~3 секунди з'являється плашка «ДОСЯГНЕННЯ» з його назвою. Кілька одразу → плашки йдуть одна за одною.
- Рейс закінчився або трамвай зійшов з рейок → під серединою екрана картка «ЗА РЕЙС»: нові досягнення за цей рейс і «Усього: N / 19». Немає нових → «Нових досягнень немає».
- Досягнення зберігаються між запусками, у браузері теж.
- За що дають:

  | Назва | Що зробити |
  |---|---|
  | До вокзалу | Доїхати до Залізничного вокзалу. |
  | Без паніки | Завершити рейс, жодного разу не натиснувши екстрене гальмо (Space). |
  | Точно в ціль | Відчинити двері на будь-якій зупинці після Погулянки, коли кабіна стоїть ближче ніж за 30 см від позначки F. |
  | Під дощем | Завершити рейс, під час якого на панелі хоч раз було «ДОЩ». |
  | Ой... | Уперше [зійти з рейок](../run-end/derailment.md). |
  | Усі доїхали | Завершити рейс, коли ніхто з пасажирів не був висаджений чи вдарений. |
  | Зачекайте! | Дочекатися [бабусю](../passengers/late-grandma.md) на площі Митна. |
  | Дідусь устиг | Випустити [дідуся](../passengers/hurrying-grandpa.md) на Дорошенка. |
  | Миротворець | Заспокоїти [пасажира напідпитку](../passengers/difficult/drunk.md) розмовою. |
  | Слово водія | Виконати обіцянку [бабусі](../passengers/difficult/grumpy-grandma.md): 20 секунд плавної їзди. |
  | Квиток, будь ласка | Попросити пасажирку [оплатити квиток](../passengers/difficult/fare-check.md), і вона заплатить. |
  | Відбився | У [бійці](../passengers/difficult/fight.md) збити натиск пасажира до нуля. |
  | Улюбленець пасажирів | Завершити рейс з репутацією 90 або більше. |
  | Чисті руки | Завершити рейс, жодного разу не [вдаривши](../passengers/hitting.md) пасажира. |
  | Гарна зміна | Мати 300 грн або більше за одну зміну. |
  | Екскурсія салоном | [Встати](../driving/standing.md) і дійти до задніх дверей. |
  | Дзень-дзелень | Подзвонити 10 разів за один рейс (B). |
  | Погляд збоку | Подивитися на трамвай [ззовні](../screen/cameras.md) (R). |
  | Так не можна | Вдарити пасажира. |
