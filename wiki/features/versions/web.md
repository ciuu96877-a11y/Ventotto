# Гра в браузері

## Опис

Є версія, яка грається прямо в браузері, посилання на неї в README репозиторію. Гра та сама, але трохи спрощена, щоб швидше працювати. Веб-версія на GitHub Pages оновлюється сама щоразу, коли в гілку `main` потрапляють зміни.

## Поведінка

- Відкриваєш веб-версію → браузер спершу завантажує гру, близько 295 МБ, тож першого разу доведеться почекати.
- У `main` з'явилися зміни → через кілька хвилин на GitHub Pages уже нова версія гри.
- Відкриваєш веб-версію → місто вже зібране наперед, тож гра стартує швидше.
- Будинки й предмети далі ніж ~165 м від трамвая не показуються, вони з'являються, коли під'їжджаєш.
- Тіней немає на будь-якій якості графіки.
- Людей менше, ніж на комп'ютері:
  - на тротуарах 6 перехожих на будь-якій якості графіки (на комп'ютері 14–34);
  - біля стін розмовляє одна пара (на комп'ютері три);
  - на зупинці, крім постійних пасажирів, чекає одна людина (на комп'ютері три).
- Перехожих далі ніж ~85 м не видно.
- У [налаштуваннях](../start/settings.md) немає перемикача «Повний екран».
- Деякі значки замінені простими символами: ◆ → `>`, ● → `*`, ○ → `o`, ← → `<`, ◉ → «П».
- Шрифт простіший, а лічильник пасажирів трохи дрібніший.
- Усе інше (керування, [ходьба салоном](../driving/standing.md), пасажири, їхні [жести й розмови](../passengers/life.md), [погода](../route/rain.md)) працює так само, як [на комп'ютері](desktop.md).
